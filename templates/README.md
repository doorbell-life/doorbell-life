# templates

錯誤頁範本，由 `pnpm build` 產生到 `templates/dist/`（每日流程會更新離線內容）。

| 路徑 | 狀態碼 | 內容 |
| --- | --- | --- |
| `{語言}/{狀態碼}.html` | 400、401、403、404、405、408、410、414 | 錯誤說明＋短停留卡片元件 |
| `{地區}/{429,503}.html` | 429、503 | 離線內容＋等待輪播元件；元件失效時留下離線內容 |
| `{地區}/{500,501,502,504}.html` | 500、501、502、504 | 純靜態，不需要 JavaScript：求助專線、宣導數字、可快取的待認養個案 |

這些檔案本身不設定狀態碼，狀態碼由網頁伺服器設定（見 `configs/`）。失蹤人口個案不會出現在任何離線頁。
